# Карта представителей

Локальная папка: правите города здесь → собираете → пушите `site` на GitHub Pages.

## Как добавить город

1. Откройте `cities.json`.
2. Добавьте объект:

```json
{ "name": "Сочи", "code": "СОЧ", "x": 14.0, "y": 72.0 }
```

- `name` — на карте и в списке  
- `code` — три буквы в плашке списка (МСК, СПБ…)  
- `x`, `y` — позиция маркера в **процентах** от ширины/высоты карты (0–100). Левый верх = `0, 0`.

3. Запустите сборку:

```bat
build.bat
```

или:

```bat
python build.py
```

4. Проверьте `../russia-cities.png` и страницу `predstaviteli`.
5. В репозитории `site`: `git add` → `commit` → `push`.

## Файлы

| Файл | Назначение |
|------|------------|
| `base-map.png` | Чистая карта без городов (не трогать без нужды) |
| `cities.json` | **Единственный** список городов |
| `build.py` / `build.bat` | Рисует карту и обновляет HTML |
| `../russia-cities.png` | Результат для сайта |
| `../index.html` | Список городов (блок между маркерами) |

## Подгонка точки на карте

Если маркер мимо города — чуть меняйте `x` / `y` и снова `build.bat`.  
Шаг 0.5–1.0 обычно достаточно.

Подписи **не наезжают**: скрипт сам выбирает сторону (право/лево/верх/низ).  
Принудительно: `"side": "left"` (или `right` / `top` / `bottom`).
